# VoyaAi 微信小程序开发路线

## 当前版本：消费端视觉第一阶段

已完成：

- 蓝白移动端主题、首页风景 Hero、定位/天气、搜索入口。
- 首页八个快捷入口、热门城市横滑卡片、精选攻略卡片。
- 底部四栏：首页、攻略、行程、我的。
- 城市搜索与城市网格页。
- 城市 → 景点列表 → 景点详情链路，使用真实公开接口。
- 景点详情的收藏/导航交互入口。
- 攻略列表、攻略详情、行程首页、行程详情、AI 助手、酒店、美食、消息、更多功能页面壳。
- 微信登录、Token、本地用户资料和头像能力继续保留。

其中攻略、行程、AI、酒店、美食、消息、收藏等页面当前是视觉和交互壳，数据接口尚未全部接入；页面中已使用“即将上线”或空状态，不把演示内容伪装成真实业务数据。

## 后续开发顺序

### 第二阶段：攻略真实业务

后端新增攻略分页、详情、标签和发布状态接口；小程序攻略列表接入推荐/最新/最热和地区筛选，详情接入作者、标签、日期、Day 行程。

### 第三阶段：收藏、点赞与浏览记录

复用 `voya_ai_favorite`、`voya_ai_like`、`voya_ai_view_log`，实现景点和攻略收藏/点赞，增加“我的收藏”和“浏览历史”，接口统一要求小程序 Token。

### 第四阶段：行程管理

实现行程、行程日、行程项 CRUD；小程序增加行程创建、日期、预算、人数、景点安排和行程详情时间线。

### 第五阶段：AI 助手

确定模型服务和调用方式后，新增会话与消息接口；AI 根据城市、天数、预算和偏好生成行程草案，用户确认后写入行程表。模型密钥只保存在后端环境变量。

### 第六阶段：酒店、美食、消息和发布

为酒店、美食、消息建立真实数据接口，补充缓存、分页、错误态、真机 HTTPS 域名和微信公众平台合法域名配置。

## 本地运行

在微信开发者工具导入当前目录，开发阶段后端地址仍是 `http://localhost:8080`。重新编译前确认后端已经启动，并在工具本地设置中关闭合法域名校验。真机调试和发布必须改为备案 HTTPS 域名。
